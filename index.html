CloudVault

Cloud File Storage with Encryption and CDN

Secure storage through file segmentation and encryption.

Overview Features Workflow Security CDN & HTTPS

Project Overview

This Python Flask application divides uploaded files into 1 MB blocks, encrypts each block, and stores the encrypted data in Garage, an S3-compatible object storage service.

Users can download encrypted blocks or retrieve and decrypt the original file.

Key Features

  • File segmentation into 1 MB blocks
  • Fernet encryption of stored blocks
  • Object storage using Garage
  • Download of encrypted blocks in a ZIP archive
  • Original file retrieval and decryption

How It Works

  1. The user uploads a file.
  2. The application divides it into blocks.
  3. Each block is encrypted before storage.
  4. Encrypted blocks and metadata are saved in Garage.
  5. The user downloads encrypted blocks or the decrypted original file.

Security

Fernet provides authenticated symmetric encryption. The encryption key and storage credentials must remain private.

This documentation page does not contain secret keys or connect to the local backend.

CDN and HTTPS

A Content Delivery Network distributes website content through geographically distributed infrastructure.

This documentation site will be published using Cloudflare Pages, which provides HTTPS and global content delivery.

The current storage backend runs locally. Connecting a public cloud storage provider such as AWS S3, Azure Blob Storage, or Google Cloud Storage remains a separate task if required by the assignment.
